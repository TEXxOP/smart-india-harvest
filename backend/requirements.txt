# Disease detection (ViT).
# torch + transformers are deliberately NOT here. Importing them cost ~225 MB
# RSS, which pushed the service to ~500 MB against Render free tier's 512 MB
# ceiling. The same ViT exported to ONNX (backend/disease_model/model.onnx,
# 22 MB, committed) runs under onnxruntime for ~35 MB instead. The 17 MB
# onnxruntime wheel also replaces a ~200 MB torch wheel, so builds are far
# faster. Re-export with `python export_disease_onnx.py` if the model changes;
# that script is the only thing that needs torch, and it runs on a dev machine.
onnxruntime==1.23.2
